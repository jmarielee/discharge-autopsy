# Build documents

Plans written 1–2 August 2026, before the build. They are kept because the
pre-registration record is only meaningful alongside what was planned.

They are not rules and they are not current. File names, deliverables, and folder
shape changed during the build: `01-build-blueprint.md` maps files that do not
exist, `03` names a taxonomy filename that became `reference/taxonomy.md`, and
`05` specs a seeded corpus that was not built.

The shipped repository is canonical. Nothing in this folder governs it.
